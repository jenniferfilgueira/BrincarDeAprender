# Brincar de Aprender
Este repositório reúne os jogos desenvolvidos para o projeto de extensão Brincar de Aprender, cujo objetivo é promover o desenvolvimento de habilidades motoras e cognitivas de estudantes da APAE por meio de atividades lúdicas e interativas.

Os jogos foram projetados para estimular a coordenação motora, o raciocínio lógico, a atenção, a memória e outras competências essenciais, utilizando a tecnologia como ferramenta de inclusão e aprendizagem.
